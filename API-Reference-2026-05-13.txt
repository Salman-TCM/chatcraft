============================================================
API CATEGORIES
============================================================

- Authentication: API token management
- Contacts: Contact management endpoints — supports lookup by numeric ID, publicId, or contactId
- Widgets: Chat widget (AI agent) management
- Conversations: Conversation endpoints — search by contact email/phone to find conversation IDs
- Messages: Message endpoints
- Forms: Form management and submission endpoints
- Flows: Flow automation endpoints — create, trigger, and manage flows
- Functions: AI function definition management
- Tags: Tag management endpoints
- Custom Fields: Custom field definitions and contact field values
- Pipelines: Sales pipeline management with stages and deals
- Pipeline Deals: Manage contacts/deals within pipeline stages
- Landing Pages: Landing page management
- Commerce: Commerce store management — create, update, and manage your webshop stores
- Commerce Products: Product catalog management — list, add, update, and delete individual products in a store
- Commerce Checkout: Shopping cart and checkout — create payment intents and confirm orders
- Commerce Public: Public storefront endpoints — no authentication required, use for customer-facing integrations
- Keywords: Cross-channel keyword trigger rules
- Automations: Event-driven automation rules
- Widget Management: Widget and function management — enable/disable AI, pause/unpause, assign functions, update settings. Designed for use with Flow External Request nodes.
- Wallet: Digital wallet pass management — create programs (membership, punch card, points, coupon, event ticket, prepaid balance, business card), issue cards, perform actions (punch, redeem, check-in), and send push notifications to Apple Wallet and Google Wallet

Authentication

GET /api/tokens
  Summary: List all API tokens
  Description: Get all API tokens for the authenticated user. Supports both session auth (dashboard) and Bearer token auth (programmatic).
  Responses:
    200: List of API tokens
      Returns: Array of ApiToken
    401: Not authenticated

POST /api/tokens
  Summary: Create a new API token
  Description: Generate a new API token programmatically. The full token value is only returned once in the response — save it securely. Supports both session auth (dashboard) and Bearer token auth (programmatic).
  Request Body (JSON):
    name: string (required) - A name/description for this token (e.g. "Production Server", "Staging")
  Responses:
    201: Token created successfully
      id: integer - Token ID
      name: string - Token name
      token: string - The full API token — save this, it will not be shown again
      tokenPrefix: string - First 12 characters of the token (for identification)
      message: string
    400: Token name is required
    401: Not authenticated

DELETE /api/tokens/{id}
  Summary: Delete an API token
  Description: Permanently revoke and delete an API token. Supports both session auth (dashboard) and Bearer token auth (programmatic). A token can delete itself.
  Parameters:
    path:id [integer] (required) - Token ID to delete
  Responses:
    200: Token deleted successfully
    401: Not authenticated
    404: Token not found

    path:serial [string] (required) - Card serial number
